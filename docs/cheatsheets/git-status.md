공개용 샘플이다. 사내 원격 주소나 계정은 적지 않는다.

| 상황 | 명령 | 보는 것 |
| --- | --- | --- |
| 지금 바뀐 파일 | `git status` | 추적 여부, 스테이징 여부 |
| 내용 차이 | `git diff` | 아직 스테이징하지 않은 변경 |
| 최근 기록 | `git log --oneline -5` | 최근 5개 커밋 제목 |
| 원격과 차이 | `git status -sb` | 현재 브랜치가 앞섰는지 |

브랜치를 지우거나 이력을 고치는 명령은 여기 넣지 않는다. 실수한 글은 파일을 수정한 뒤 새 커밋으로 푸시하면 사이트가 다시 빌드된다. 직전 정상 커밋으로 되돌릴 때도 강제 푸시 대신 되돌리는 커밋을 만든다.

```bash
git status -sb
git diff
git log --oneline -5
```
